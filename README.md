# CronPilot

**Flight timers, GPS tracking and offline navigation references for Android.**

CronPilot is an Android flight timing and GPS companion for pilots, aviation enthusiasts and flight simulator users.

## Features

- Three flight timers and twelve approach-time presets
- Foreground GPS track recording and GPX export
- Track plotter with compass ring and runway-up orientation
- Offline airport and radio-navigation references
- Nearest-airport information and position reports
- Magnetic variation estimates using WMM2025
- Optional navigation database updates from GitHub
- Optional Microsoft Flight Simulator 2020/2024 connectivity through CronPilot Sim Bridge for Windows

## Current Version

CronPilot Android 1.5.0 (Build 10)

## Optional Windows Companion

CronPilot Sim Bridge connects the Android app to Microsoft Flight Simulator over a trusted private local network.

Windows companion project:
https://github.com/SAGMSoftware/cronpilot-windows-bridge

## Navigation Data

CronPilot includes offline reference data derived from OurAirports. Updated reference data may be downloaded through the app when available.

Navigation data repository:
https://github.com/SAGMSoftware/cronpilot-navdata

## Aviation Safety

CronPilot is not a certified aviation navigation instrument or emergency service. Its reference data and calculations must not be used as the sole basis for safety-critical flight decisions. Always use current official aviation information and approved instruments.
